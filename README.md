# Browser

Лёгкий браузер для Android с нижней адресной строкой. Написан на Kotlin с Jetpack Compose и системным WebView.

## Возможности

- Ввод адресов и поиск через Google в одной строке. Подсказки подбираются локально по популярным и недавно открытым доменам.
- Вкладки с восстановлением открытых адресов после перезапуска. Есть навигация назад и вперёд, обновление страницы и копирование ссылки.
- Плавающая панель с размытием сворачивается до домена при прокрутке вниз. При вводе адреса она расширяется вместе с клавиатурой.
- Статус-бар подбирает цвет по верхнему краю загруженной страницы и сохраняет его при прокрутке.
- Русский и английский интерфейс. Светлая и тёмная темы следуют системным настройкам.

## Запуск

Для сборки нужны Android SDK 37 и JDK 25. Для запуска приложения подойдёт устройство или эмулятор с Android 16 (API 36) или новее.

Открой корень проекта в Android Studio, дождись синхронизации Gradle, выбери устройство с API 36 или 37 и запусти конфигурацию `app`.

Сборка и тесты из терминала:

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Для сборки оптимизированного APK выполни `./gradlew :app:assembleRelease`. Локальная release-сборка подписывается отладочным ключом Android Studio.
